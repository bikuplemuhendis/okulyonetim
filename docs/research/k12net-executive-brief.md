# K12NET yönetici özeti

Kaynaklar: `k12net-product-features.md`, `k12net-customer-websites.md`, `kampustakip-current-inventory.md`.

## Rakip

Atlas Eğitim Yazılımları’nın 2004’ten beri satılan K-12 SIS’i. 3 portal, 44 modül, cloud + markalı mobil. TR özel okul pazarında TED, FMV Işık, ENKA, Terakki, Sınav, Final, Anabilim, BLIS vb. **55 doğrulanmış + 880 referans logolu** kurum; satıcı 4.358 TR kurumu iddia ediyor.

## Biz vs onlar

KampüsTakip kampüs operasyonunda önde (canlı bina, web yoklama, kiosk, RBAC, KVKK, audit). K12NET akademik-finans-operasyon genişliğinde önde; arayüz WebForms kuşağı.

## Geçmek için şart

Not defteri, ödev, mesaj, takvim, davranış, sağlık, servis, kütüphane, ücret, kulüp, etüt, ön kayıt, anket, personel devam, nöbet, belge, ziyaretçi, yemek, başarı, veli randevu, stok, konu — hepsi modern rol portallarında ve öğrenci 360°’de. UX: sade IA, ikonlu nav, veli/öğrenci “tek bakışta hayat”.
